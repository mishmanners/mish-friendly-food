# Card Graphics

This folder contains graphics for the different card styles used in the Mish Friendly Food project. Each style has a unique design to enhance the user experience.

## Styles

- **Anime**: Fun and cute anime-themed graphics.
- **Colorful**: Vibrant multi-colored stripes and accents with a warm cream background.
- **Corporate**: Professional and clean designs.
- **Cute**: Adorable and colorful designs.
- **Elegant**: Sophisticated card with decorative borders and corner accents on light gray.
- **Gradient**: Subtle blue-to-white gradient with light blue border.
- **Minimalist**: Clean white background with simple black lines and accent.
- **Modern**: Sleek and minimalist graphics.
- **Nature**: Earth-toned green card with organic leaf-inspired corner decorations.
- **Vintage**: Warm beige background with brown double border and corner squares.

## Card Specifications

- **Dimensions**: 350 x 200 pixels
- **Format**: PNG
- **Purpose**: Blank backgrounds for overlaying translated text

## Usage

These graphics are used as backgrounds for the exportable cards in the application. When users translate their dietary requirements, they can choose a card style and export their translation as a downloadable image with the text overlaid on these backgrounds.
